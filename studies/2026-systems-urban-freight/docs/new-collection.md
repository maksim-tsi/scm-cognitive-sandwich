# New LLM collection is a separate reproduction level

The public offline package does not authorize, launch or resume any live run.
It preserves the controller, original canonical action schema, provider adapters,
profile settings and scenario-message construction for scientific inspection.
The HTTP worker is deliberately disabled. The private host was replaced with a
reserved example.invalid endpoint; it is not a substitute model service.

A future separately approved collection must use a new journal and directory,
never consume/reset historical attempts or replace old trajectories. Requalify
current model availability, pricing, transport, structured modes and budgets on
non-scientific fixtures before a new prospective freeze. No prompt tuning on
exposed scientific cases. Missing/incomplete/model-format states remain separate.
No retries/replacements; unknown delivery, 429, budget or integrity failure stops
collection according to the approved protocol.

Historical profiles: Qwen `qwen3.8-27b-ud-q4_k_m` local, DeepSeek `deepseek-flash`,
Mistral `mistral-small-2603` native structured mode, and OpenAI `gpt-6-luna`
Responses JSON actions. Inspect the exported provider modules and collection
configuration for exact generation settings, seeds, token and pacing guards.
OpenAI preserves commentary/final_answer phase history; only the sole validated
final action executes. No images are transmitted to experimental models.

For R1: 22 trajectories/provider; <=7 responses/trajectory, <=154 requests/provider,
616 overall; original $2/provider/$6 external ceiling and 8h are historical
conditions, not a new spending authorization or current-price quotation.
Qwen's long-history exact token counter additionally needs the qualified llama.cpp
revision/vocabulary/template artifacts recorded in `token_budget.py`; model weights
and tokenizer binaries are not redistributed. EVAL30 and its Luna extension have
separate documented budgets and serving history. Profiles are experimental
conditions, not interchangeable wrappers. Repeated generations may differ even
at temperature zero; no identical-response guarantee is made.
